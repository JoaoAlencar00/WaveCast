# WaveCast

Estudo de CSS Grid e Flexbox aplicado ao layout de uma interface de podcasts.

## Conteúdo disponível

- Estilos para menu lateral, navegação, seções e cartões.
- Definição de áreas e colunas com CSS Grid.
- Composição de elementos com Flexbox.
- Media queries para diferentes tamanhos de tela.
- Imagens de podcasts, ícones e logotipos.

## Estrutura

- `grid-flex/`: regras de organização do layout.
- `base.css` e `responsivo.css`: estilos gerais e adaptações.
- `style/`: outra organização dos arquivos de estilo.
- `Imagens/`, `Icones/`, `Logos/` e `imagens/`: recursos visuais.

## Como estudar este repositório

Abra os arquivos CSS em um editor e consulte as regras de layout. A versão atual não contém um arquivo HTML de entrada; por isso, ainda não é possível executar a interface completa diretamente a partir deste repositório.

Para uma demonstração navegável, o próximo passo é adicionar a estrutura HTML que utiliza essas classes e consolidar as pastas duplicadas de estilos e recursos.

## Aprendizados

Organização de áreas com `grid-template-areas`, posicionamento de cartões, composição com Flexbox e adaptação visual com media queries.

Este repositório registra um exercício de layout. As marcas e imagens de podcasts pertencem aos respectivos titulares.
